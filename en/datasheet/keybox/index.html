Keybox · Basic series

9001 B — one door, 32 key hooks

9006 B — six compartments

9500 B — 216 key hooks

The Basic series is based on simplicity and security. The key cabinets are equipped with a keypad for entering codes and programming. The key cabinet has a small green diode above the keypad that indicates that the cabinet is active and blinks faster when it is in service mode. The key cabinets are available in various models with 18, 32 or 216 key hooks or, alternatively, with 6 small compartments. All key cabinets can be expanded using Expansion cabinets, by up to 15 cabinets in any combination. This means that there can be 96 compartments in just one key management system, which are all controlled via just the one keypad.

Keybox · System series

9001 S — one door, 32 key hooks

9006 S — six compartments

9500 S — 216 key hooks

System is a series of key cabinets that are a bit more intelligent and flexible, where the keypad comes with a display to provide a good overview and easy programming. The cabinets can handle up to 500 users (codes with 1-8 characters) and store up to 3,600 events. System can be administered via KeyWin Light. The cabinets are available in various models with 18, 32 or 216 key hooks or, alternatively, with 6 small compartments.

Keybox · Keycontrol series and IntelliPin

Cabinet opened, with key strips

14 key slots on each strip

KR security cabinets

Your Keycontrol system can include everything from a few up to several thousand keys. You can easily add strips and key space to your key cabinet, or expand the key management system with more cabinets, to meet your growing needs. Pair the IntelliPin and key together, then place them on the strip on the wall or in a cabinet. Each IntelliPin carries a unique ID, which means you can easily identify the status of individual keys directly from the web application KeyWin6. The key cabinets have a display with a simple menu and search function. The cabinets are also equipped with battery backup, alarm and 14 key slots on each strip. Choose either locked or unlocked key slots, and on the large models between a sheet metal or glass door. SSF3492 security rating.

Keybox · Software

KeyWin Light — for the System series

The KeyWin Light PC program gives a better overview of the System series. You can check and control the system by plugging a USB flash drive with a service code into the cabinet. The event log is also downloaded to the USB flash drive, which you can then process on a computer.

KeyWin6 — for the Keycontrol series

KeyWin6 is the latest version of the market's most comprehensive administrative tool for securely managing keys and valuables. One or more administrators can manage key cabinets and keys with the highest possible precision, from anywhere in the world. Choose between the KeyWin6 IoT cloud service based on IoT technology through Microsoft Azure or an on-premises software installation.

What KeyWin6 manages

Users

Selected or random PIN code · login via PIN code or card reader · option to change code at the cabinet · deactivation of users · validity period · individual language settings · restrict number of key removals · user type (dual level authentication) · advanced search function.

Event log

Log from PC and cabinet · select what a log displays · intelligent search function · sort by date or events · clear alarm indications · reports as PDF document · alarm forwarded to e-mail.

Key cabinets

Display screen with search function · information about who has a key · service menu for configuration · administration code with full authorisation · automatic or static IP address · top 10 most frequent users and most frequently used keys · statistics on keys removed and on the total number of keys and groups in the system.

Keys

Time limit · searchable hidden key ID · colour coding of keys · graphic overview of keys · a key in one or multiple cabinets · free or fixed key position.

Settings

Cabinet overview · administration overview · import users via XML · export users or keys to PDF · number of characters for codes · add or remove card reader · product information · e-mail settings for alarm incidents · choice of language · door, key and burglar alarm · smart mode · connection for external reader and external alarm.

Groups, administrators, booking and reports

Groups for users, keys and compartments · time channels · edit administrator permissions · selection of cabinet for administration · activities registered in log · booking a specific key · daily statistics on alarms and key removals.
