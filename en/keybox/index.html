Keybox

Basic series

Open with a code.

The simplest step away from a key box with one key: everyone with access has their own code. No network, no server, no management program.

  • Open with a personal code on the door
  • Works on its own — no network or server needed
  • Ready to use at once, minimal installation

System series

Who, what, when.

The same cabinet, now with a display. Users and rights are set per person and every opening is recorded. After an incident it can be established who opened the compartment.

  • Users and rights configurable per person
  • Every issue and return goes into the log
  • Traceable afterwards: who, what, when

Keycontrol series

Every key recognised.

The most intelligent level: every key position is identified electronically. The cabinet knows which key hangs where and which is out — in real time, without signing off by hand.

  • Electronic identification per key position
  • Real-time view of which key is present or out
  • Works with IntelliPin and KeyWin for full logging

Expansion series

Add, do not replace.

Expansion cabinets have no panel of their own. They hang beside a Basic, System or Keycontrol and are opened from that same control. If the number of keys grows, another cabinet is added — the codes and rights stay as they are.

  • No control of its own — works under the main cabinet
  • The same codes and rights continue to apply
  • Expand without replacing the system

Key strips

Start with one strip. Build it out when you need to.

You decide how many key strips go in the cabinet. Lockable, non-lockable, or both mixed in the same cabinet. That keeps the initial outlay small and lets you add a strip later as the number of keys grows.

Size

Choose your size.

Every series comes in the same sizes. You choose the control — Basic, System or Expansion — and the size separately, from a single interior to a large cabinet.

One interior The full interior behind one door, fitted out with key hooks.
Two drawers An interior plus two drawers, each released separately.
Six drawers Six separate compartments for departments, buildings or vehicles.
Large version For a set of keys that no longer fits in one cabinet.

IntelliPin

The key fob that gives itself away.

The IntelliPin is not packed with electronics. Its strength is simpler: every fob has its own unique identity. The cabinet reads it, KeyWin records it.

That makes it possible to see afterwards who took which key and at what moment. No list on the wall, no sign-out book.

  • A unique identity per fob — no two alike in the system
  • Every issue and return goes into the log van KeyWin
  • The bunch fixed to the fob, the fob fixed in the position

KeyWin6 · software

The brain behind every cabinet.

KeyWin6 controls all your KeyBox cabinets from one environment. Keys, users and events at a glance — wherever you are, on any device. Available as a cloud service through Microsoft Azure or as a local installation on your own server.

  • Cloud through Microsoft Azure or locally on your own server
  • Find the right key or user in a single search
  • Links to access control through an API or sync engine
