SWAT-box

One key, right by the door. A compact safe with a PIN code or card, for the place where access has to be quick — and must stay traceable.

How it works Readers Inside Dimensions Control Questions

Code in, drawer out.

After a valid code or card the drawer slides out and the key is released. One position, one key — no searching, no doubt about who has it.

  • The key stays with the safe Attached to a steel wire with a tamper-proof ring. The key does not leave through the door.
  • Wall mounting, compact Mounted beside the door it unlocks. Dimensions on request.
  • Also for fobs and tags Besides keys, also suitable for fobs and tags on the same steel wire.

Opening with a PIN code or card.

The safe is supplied with a PIN keypad (see above) or with a card reader.

Card reader Opening with an access card instead of a code. Integration with existing access control: by arrangement.
External control A front without a keypad or reader. Release then runs through another source.

Inside.

A steel drawer, no sharp edges. One position per safe.
The key is fixed to the safe and cannot be removed from it.
Also suitable for fobs and tags on the same steel wire.

Where the SWAT-box is used.

Emergency key Available in an emergency, behind a code instead of behind glass.
Data centre The rack key in the aisle where it belongs, instead of centrally at the desk.
Plant room and lift The plant room key beside the door, not in a drawer in the office.
Vehicles A car key or fob per vehicle, attached to the safe.

Dimensions.

Compact enough to fit beside a door or in a vehicle. The round front covers the opening.

Width 8.9 cm · 3½"
Height 13.3 cm · 5¼"
Depth 15.9 cm · 6¼"
Front Round, 15.2 cm · 6"
Version Flush-mounted, the front level with the surface

Two ways of controlling it.

With management software behind it, or entirely without — then you drive every position yourself.

GFMS Management software in the browser, with no installation on the workstation. Rights, users and the log for all safes in one place. The same software as behind the Security Asset Manager. KSI helps set up the management, whatever the size of the site or the technology already in place.
Direct Control A version without built-in KSI electronics. You drive every position and door yourself, through your own hardware or access system — with no intermediary software.
