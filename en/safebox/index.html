Key Management Systems

Safebox

A solid steel key safe running on batteries, opened with a code, an RFID tag or an emergency key. For keys and access cards that belong behind a lock but must stay reachable.

Three ways in. Never by accident.

Day-to-day use goes through the code or an RFID tag. If the battery runs flat, the cabinet opens with the separate key or with a 9 volt battery combined with the PIN code.

A code on the keypad Up to 50 users, each with their own code. Programming is done on the keypad, without a computer or software.
RFID key tag A tag carrying personalised data, instead of a code. The administrator decides where the tag gives access.
Emergency opening With the separate key, or with a 9 volt battery and the PIN code. The emergency key belongs with the administrator, not with the cabinet.

One version, 58 positions.

Solid steel with a 5 mm door and a hinged key rack, so you can also reach behind the first row. Available in black.

Key hooks as standard, with one hinged key rack.

RFID key tag

Opening without a code.

Every Safebox comes with one RFID key tag as standard: an access tag carrying the user data, which replaces the PIN code or the key.

As key administrator you decide what each tag gives access to. Extra tags are supplied in packs of 10.

Type 125 MHz EM
Supplied with 1 tag per cabinet
Reordering In packs of 10

Options

Two ways to unlock it.

Electric lock Available with a 12 V ASSA Abloy EL582, unlocked through your own card reader. That brings the cabinet within the existing access system.
Cylinder for emergency opening Beside the electric lock there is a mechanical cylinder, so the cabinet stays reachable in a power failure.

Where the Safebox fits.

In places where keys or cards do not have to be recorded electronically but do have to be behind a lock: a reception desk, a plant room or an office with a handful of spare keys.
