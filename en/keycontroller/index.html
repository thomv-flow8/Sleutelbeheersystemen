Keycontroller

Two locks that hold each other: the user key is released only if the control key stays behind. Mechanical, without power or software.

How it works

Never two keys free at once.

The two locks work in tandem. As long as the control key is in place, the user key can be taken. That control key then stays locked until the user key is back.

  • Bringing it back is the only way to carry on
  • No battery, no network, no management program
  • Can also be combined with a Security Asset Manager

Sealed tags

Use leaves a trace.

Every position comes with a numbered seal tag that can only be opened by breaking it. Red for user keys, white for control keys — on a round you see at a glance what has been touched.

Tags can be replaced per position and hold up to five keys together.

Bespoke

Matched to your master key system.

Non-standard sizes and numbers of positions are possible. The door lock and internal locks can be on one master key system, so the management fits your existing key plan.

Safes and wall panels work on their own, but can also be driven electronically from the Security Asset Manager.

Control

With software or without.

GFMS Browser-based management software with no installation on the workstation. The same environment as behind the Security Asset Manager. KSI helps set up the management, whatever the size of the site or the technology already in place.
Direct Control A version without built-in software: every position is driven directly. For organisations that do not want intermediary hardware or software.

What it is made of.

Material Safes Brushed stainless steel, 18 gauge Wall panels Powder-coated steel, 16 gauge
Locks High-security cam lock 19 mm (suitable for 16–32 mm), an interchangeable core in small or large format, or a mortise cylinder supplied by the customer.
Seal tags 1.9 × 3.8 × 1.3 cm, 4.1 grams. For 1 to 5 keys, in white and red.
